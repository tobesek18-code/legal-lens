DigitalOcean Server Topology Architecture

Deploy your service layout to a highly scalable DigitalOcean Droplet. This configuration details deployment using standard Nginx reverse-proxy handling and PM2 runtime execution loop persistence.

Infrastructure Notice: Verify that standard DNS values point explicitly towards target public server allocation parameters prior to issuing SSL validation scripts.
Nginx Virtual Host Config (/etc/nginx/sites-available/zartech)
server {
    listen 80;
    server_name zartechai.com app.zartechai.com;

    location / {
        proxy_pass http://127.0.0.1:8501;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;

        # Required WebSocket upgrade handling blocks for voice data stream validation
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_read_timeout 86400;
    }
}
